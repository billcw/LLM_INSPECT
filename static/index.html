Quick glossary — definitions of the AI and mathematics terms used in this lab

Terms are defined here once so later sections can stay readable. Open this glossary whenever an unfamiliar term appears.

Artificial intelligence (AI)
A broad label for computer systems designed to perform tasks associated with intelligent behavior; it does not imply consciousness.
Large language model (LLM)
A neural network trained on many token sequences to model which tokens are likely in context. “Large” is relative; this teaching model has about 135 million parameters.
Model
The parameterized mathematical function used for prediction. A checkpoint is a saved set of its configuration and learned parameter values.
Transformer
A neural-network architecture built from repeated attention and feed-forward computations, with residual connections and normalization.
Token
A vocabulary unit processed by the model. It may be a word, part of a word, punctuation, whitespace, or bytes—not necessarily a whole word.
Tokenizer / vocabulary / token ID
The tokenizer converts text to vocabulary entries; the vocabulary is the fixed set of entries; a token ID is an entry’s integer index.
Embedding / unembedding
An embedding maps a token ID to a vector. The unembedding maps the final representation to one logit per vocabulary entry; this model ties those weights.
Parameter or weight
A learned numeric value stored in the model. Parameters remain fixed during this lab’s inference experiments unless a toy lesson explicitly demonstrates training.
Activation
A temporary numeric value computed from a particular input. Activations change with the prompt even though the model’s weights do not.
Residual stream
The evolving vector at each token position to which attention and MLP outputs are added through residual connections.
Layer or block
One repeated transformer stage. In this lab, “block” avoids confusing a complete stage with its smaller sublayers.
Vector / matrix
A vector is an ordered list of numbers. A matrix is a rectangular array of numbers; multiplying vectors and matrices mixes and transforms coordinates.
Dimension / coordinate / shape
A coordinate is one numbered component of a vector; dimension is the number of components. Shape lists an array’s axis sizes, such as [6, 64].
L2 norm
The Euclidean magnitude √Σx². It summarizes overall size but does not by itself reveal meaning, usefulness, or importance.
Dot product / cosine similarity
A dot product sums coordinatewise products. Cosine similarity divides a dot product by both vector norms to compare direction rather than magnitude.
Logit
An unnormalized vocabulary score. Logit differences determine probability ratios after softmax; a logit is not itself a probability.
Softmax / probability distribution
Softmax converts logits into nonnegative values that sum to one. The resulting distribution assigns a next-token probability to every vocabulary entry.
Temperature
A sampling control applied to logits before softmax. Lower positive values concentrate probability on high-logit tokens; higher values flatten it. T=0 means greedy selection here.
Sampling
Selecting a token using the probability distribution. A lower-ranked token can be selected; sampling is not the same as always taking the largest probability.
Entropy
A measure of distributional uncertainty or spread, reported here in nats. It is not a measure of factual truth.
Forward pass / inference
A forward pass computes outputs from inputs using fixed weights. Inference uses such passes to predict or generate without updating the weights.
Attention
A weighted mixing operation: each query position scores allowed key positions and uses normalized weights to combine their value vectors.
Query, key, and value (Q/K/V)
Projected vectors used by attention. Query–key scores set mixing weights; those weights combine value vectors.
Attention head
One parallel Q/K/V attention calculation. Multiple heads produce outputs that are concatenated and projected back into the residual stream.
Causal mask
A restriction that prevents a position from attending to future token positions during next-token prediction.
RoPE
Rotary positional embedding: position-dependent rotations applied to query and key coordinate pairs so attention can use relative-position information.
Grouped-query attention (GQA)
An arrangement in which several query heads share fewer key/value heads, reducing key/value-cache storage.
RMSNorm
Root-mean-square normalization: it rescales a vector using its root mean square and learned per-coordinate weights.
MLP / SiLU
The multilayer perceptron is each block’s position-wise feed-forward network. SiLU is its nonlinear activation function in this model.
Random seed / pseudorandom generator
A seed initializes a deterministic number-producing algorithm. It lets the same sampling experiment usually be replayed in the same environment; it does not alter learned knowledge.
KV cache
Stored key and value activations from earlier positions, reused so generation need not recompute the whole prefix at every step.
EOS
End-of-sequence: a special token that may signal generation should stop.
Training / loss / gradient / optimizer
Training updates weights. Loss measures prediction error; a gradient gives local loss sensitivity; an optimizer uses gradients to choose updates.
Perplexity
exp(mean next-token loss). Lower values mean the evaluated sequence was less surprising to the model; perplexity is not truth or quality.
Intervention / no-op control
An intervention deliberately changes a computation to measure consequences. A no-op control follows the same machinery while making no effective change.
TV, JS, and KL divergence
Numerical measures of distributional difference. TV is total variation distance; JS is symmetric and bounded; KL is directional and can be unbounded.
Logit lens / probe
A logit lens reads intermediate states through an output mapping. A probe is a fitted measurement model; neither is a transcript of the model’s reasoning.
Jacobian / JVP / finite difference
A Jacobian collects local derivatives. A Jacobian-vector product (JVP) measures change along one direction; a finite difference checks it using small perturbations.

1. Tokens, scores, probabilities, and a draw

Analyze first: If you lower temperature, will token IDs, logits, their ranking, or the sampling probabilities change? Explain before moving the slider.
The smallest useful mental model

The tokenizer converts text into vocabulary IDs. The transformer computes contextual representations and vocabulary scores called logits. Software converts those scores into a distribution and selects the next token. The selected token becomes part of the next input.

This does not mean the network contains only a lookup table or cannot represent relationships about later text. Its next-token interface is not a complete description of its learned internal computations.

Token positions (#0, #1…) are different from vocabulary IDs. The same vocabulary ID can occur at multiple positions. Chips show both. Quoted token strings expose leading spaces and escaped newlines. Individual byte-level token decoding can contain replacement characters; the full decoded sequence is authoritative.

This lab explicitly uses add_special_tokens=False. It does not silently prepend BOS. The model and tokenizer identities appear under Verify & export.

Logits, temperature, and stable softmax
For T > 0: pᵢ = exp((zᵢ − max(z))/T) / Σⱼ exp((zⱼ − max(z))/T)
For T = 0: choose the first maximum logit (greedy tie-break by ID)

Subtracting the maximum prevents overflow without changing the distribution. Positive temperature preserves the ordering of the logits. It changes sampling, not the forward-pass computation. T=0 is a separate operation, not division by zero.

The model probability column always uses T=1. The sampling column uses the current slider. Probabilities use the entire vocabulary, not a renormalized top-ten list. A high token probability is not a probability that a statement is true. A displayed zero can be a rounding or numerical-underflow effect.

Sampling as a number line

Each segment has width equal to its sampling probability. Draw r uniformly in [0,1) and take the first cumulative boundary strictly greater than r. Grey combines the tail visually, but a draw still resolves to a specific vocabulary ID.

This browser exercise uses Math.random; it is independent of the seeded PyTorch generation experiment. Frequencies fluctuate, especially for rare tokens. Changing the slider clears the sample tally.

Explain it back

Explain why a token ranked second can be selected, why lowering T does not rerun attention, and why a partial token such as “Os” does not commit the model to finishing “Osaka.”

2. Follow one position through one block

First run the invented two-dimensional example. Then inspect the real block. Each displayed vector has its full values available; its norm is a magnitude, not a measure of knowledge.
The operations, in order
  1. Normalize the incoming residual vector using RMSNorm.
  2. Project the full normalized vector into queries, keys, and values. A head is a slice of the projected output; it is not limited to a disjoint slice of the original input.
  3. Apply RoPE position-dependent rotations to queries and keys.
  4. Dot queries with keys, divide by the square root of head dimension, apply the causal mask, and softmax.
  5. Use those weights to sum value vectors. Project the head outputs back to the residual width and add the attention write.
  6. Normalize again, run the gated MLP, and add its write.
h_after_attention = h_in + attention_write
h_out = h_after_attention + MLP(RMSNorm(h_after_attention))

An addition can cancel existing components. The original embedding remains a term in an algebraic expansion, not a guarantee of separately recoverable meaning. RMSNorm includes learned per-coordinate scaling; it is not merely a cosmetic display rescaling.

Maximum 64 tokens; longer prompts are rejected, never silently shortened. Block/head labels are 1-based; positions and vector coordinates are 0-based.

Why the MLP matters

The MLP transforms each position using its current contextual representation. This model projects 576 values into two 1,536-value branches. One branch passes through SiLU; the branches multiply elementwise; a down-projection returns 576 values.

g = W_gate x; u = W_up x
m = W_down (SiLU(g) ⊙ u)

For SmolLM2-135M, these MLP matrices contain 79,626,240 parameters, about 59.2% of the total. That is a parameter-count calculation, not a measure of where “intelligence” resides. SiLU is not a probability gate constrained to [0,1].

Unembedding: magnitude and angle both matter

The final raw state goes through final RMSNorm once, then the output matrix produces vocabulary logits. With tied weights, this matrix shares parameters with the embedding table.

logit(token) = h_normalized · w_token
= ||h_normalized|| × ||w_token|| × cos(angle)

Dot products are not cosine similarity alone. Weight sharing does not guarantee that an embedding reads out its own token with probability near 100%. Greedy selection chooses the largest logit; sampling need not.

Explain it back

What changes when a query position gives an earlier position more attention? Distinguish the scalar weight, the earlier position’s contextual value vector, the projected write, and the final output probability.

3. Generate and inspect every step

Before running twice, predict when the two runs must have the same distribution and when their distributions may differ.

Generation uses the sampling temperature in section 1. Existing results retain the temperature actually used.

What the random seed controls—and what it does not

A random seed is the starting integer for a pseudorandom number generator: an algorithm that produces a repeatable sequence of number-like draws. During sampling, each draw selects from the current next-token probability distribution. The seed controls that sequence of draws; it does not change the prompt, model weights, logits for an identical prefix, or what the model learned.

With base seed 42, this lab uses effective seed 42 for run 1, 43 for run 2, and so on. Repeating the same prompt, temperature, settings, and base seed in the same software environment should replay the same token IDs. If you leave the seed blank, the server creates a fresh base seed and records it in the result so the experiment can be repeated.

Different seeds are not “more” or “less” random, and nearby seed numbers do not produce meaningfully similar text. Two seeds can still select the same token—especially when one token has most of the probability. Their outputs remain identical until a sampled token differs. After that divergence, the prefixes differ, so later logits as well as later draws may differ.

At T=0, the lab chooses the largest logit directly, so it makes no random draw and the seed has no effect. At T>0, a seed improves repeatability but does not guarantee identical results across different PyTorch versions, model revisions, devices, or numerical implementations.

Weights, activations, cache, and context are different

Weights are learned parameters. Activations are computed for the input. A KV cache retains prior keys and values during generation. Conversation history is text supplied to the model. None of these is interchangeable.

Without a cache, this lab reprocesses the whole prefix at each step. With a cache, it processes the prompt once and then only the new token’s representation, attending to cached prior keys and values. Cached and uncached paths should agree within numerical tolerance.

The same prefix has the same logits under deterministic settings. After runs choose different tokens, their prefixes differ, so subsequent logits may differ. Equal-length inputs use the same dense architecture; token length, cache state, and output budget change the work. Generated tokens are appended; this loop does not revise earlier token IDs.

Run r uses base_seed + r (r starts at zero), so repeated requests replay the same set of runs, while runs inside one request use distinct random streams.

5. Attention patterns and the uniform reference

Choose an individual head before interpreting a mean. A bright cell is a measured weight, not by itself evidence that the corresponding original word caused the answer.
What the axes and aggregation mean

Rows are query positions; columns are key/value positions. At later layers, those positions contain contextual representations, not isolated original-word meanings. The grey upper triangle is causally masked.

An individual head’s raw row sums to one. A mean of heads also sums to one. A cellwise maximum is an envelope from potentially different heads and is not a probability distribution. Its cells do not have a universal “4× noise / 5× real” threshold.

For row i (0-based), the uniform reference is 1/(i+1). The × uniform display divides by that reference; it does not alter the model or perform an experimental intervention. Raw probabilities and reference ratios must not be confused.

Grouped-query attention shares key/value projections between groups of query heads. Here, 9 query heads use 3 KV heads. Sharing reduces the cache size; it also constrains the architecture. Its practical effect cannot be declared negligible solely because a prompt is short.

Bottom-row profile across layers

Position 0, self-position, and the largest other weight. “Other” does not mean semantic importance. Compare raw percentages across prompt lengths; reference multiples have length-dependent ceilings. Zero values are shown as gaps on the logarithmic graph, with exact numbers in the table.

What the attention-sink research establishes

Some models allocate unusually large attention to early positions. One research-supported account is that sinks reduce harmful over-mixing. This is not a demonstrated explanation for every bright cell in this model.

Barbero et al. report Gemma 7B’s 4,096-context RULER score falling from 82.57 to 0.00 after removing BOS. StreamingLLM reports Llama-2-13B perplexities of 5158.07, 5.40, and 5.60 for the stated cache variants on a roughly 65,000-token PG-19 book. Those are external experiments, not results from your prompt. Barbero et al.; StreamingLLM.

The first column and diagonal may carry useful content as well as positional effects. Do not automatically exclude them as “only plumbing.” Inspect value contributions and test an explicit intervention.

6. Intervene, then measure what changed

Choose a target and contrasting token. Predict the direction of the change before removing a head.
Define the intervention before interpreting it

Zero head output: set that head’s slice of the concatenated weighted-value output to zero immediately before the output projection at the selected block. Model weights are untouched.

Uniform attention: replace the head’s weighted-value sum by the arithmetic mean of values over causally allowed positions. This really changes the computation; merely rescaling the heatmap does not. This is an inference-time intervention, not a reproduction of the trained uniform-attention baseline in Wiegreffe and Pinter, §3.2.

Removing a head removes both content-related and sink-related contributions. It cannot isolate a sink mechanism. Off-distribution interventions and nonlinear interactions limit interpretation. Effects for individual heads need not add to the joint effect. A top token can stay unchanged while its probability changes substantially.

TV(p,q) = ½ Σᵥ |pᵥ − qᵥ|       (entire vocabulary, T=1)
Δ probability (pp) = 100 × (p_after(target) − p_before(target))
Δ logit difference = (z_target − z_contrast)_after − (z_target − z_contrast)_before

7. Where the learned weights come from

Separate computing a loss, differentiating it, and updating weights. They are three different operations.
Teacher forcing and shifted targets

During next-token training, each position is used to predict the following token. The target sequence is shifted by one position. A causal mask prevents a position from reading its target even though many positions can be trained in parallel.

position 0 input: The       target: capital
position 1 input: capital   target: of
loss at a position = −ln p(target)
mean loss = sum(losses) / number of supplied targets

The exact tokenization may include leading spaces. The live table uses the actual IDs. Its perplexity is exp(mean loss), using natural logarithms. It describes how surprising this text is to the model, not whether the text is true.

A tiny optimizer step you can check

This separate invented 3-class, 2-input classifier displays every weight, probability, gradient, and update. It never trains or changes SmolLM2.

Training is not the same as inference or gradient analysis

Training uses a loss, gradients, and an optimizer to update weights. Inference uses the learned weights without an optimizer update. Gradient analysis can differentiate a frozen model with respect to activations without training its weights. The Jacobian experiment below does that.

This lab defaults to the base SmolLM2-135M checkpoint. A base model completes text; instruction-tuned models have additional training for following instructions. A chat template is a formatting convention, not that training itself. The default lab does not silently add a chat template. Model card.

8. Intermediate readouts and experimental probes

Advanced interpretation. Readouts are measurement methods, not transcripts of the model’s thoughts. A poor readout does not prove that useful information is absent.
Raw logit lens, with explicit final normalization

Apply the final normalization and unembedding to each raw stage, asking what this decoder reads from that representation. The table separates embedding, all raw block outputs, and final RMSNorm. The post-normalization row is unembedded without normalizing again.

The final row must reproduce model logits, but that check alone does not validate earlier readouts. The logit lens incurs extra normalization and vocabulary-projection work; it is not computationally free.

Optional affine probe — fit on one set, evaluate on another

This lab uses ridge regression to predict the remaining residual update with an intercept. It fits final raw states, not labels and not KL loss. It is therefore an affine final-state regression probe, not the published KL-trained tuned lens. The tuned lens is a related research alternative.

predicted_final(h) = h + mean_delta
  + (h − mean_training_h) × centered_training_hᵀ × coefficients

All prompts used for calibration and evaluation are visible below. Exact token-sequence overlap is rejected. Reported held-out KL compares the model’s final distribution with the probe, raw logit lens, and constant final-state mean. Lower is better. A small corpus is not a validated general-purpose interpreter; if you tune settings on the held-out set, use a new test set for final evaluation.

May take time on CPU. The fit is session-memory only; no legacy pickle is loaded. Export the report for exact prompts, settings, hashes, and measurements; rerun fitting to reproduce the probe.

Local Jacobian experiment — sensitivity, not J × h prediction

A Jacobian is a derivative. The proper local approximation is f(h+εv) ≈ f(h)+εJ(h)v, not generally f(h) ≈ J(h)h.

Select one coordinate of the last-position residual vector after a block. Hold the earlier positions fixed. Compare an autograd Jacobian-vector product (JVP) with a central finite difference and with the actual perturbed final pre-normalization state. This does not estimate the whole sequence’s Jacobian or prove a global predictor valid.

Try several epsilon values. Too small causes float32 cancellation; too large leaves the local regime. No model weights are updated. This replaces the old unvalidated averaged-Jacobian readout.
